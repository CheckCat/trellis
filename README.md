# Trellis

Платформа для прохождения учебных курсов, которая работает **целиком на вашем
компьютере**. Никакого сайта в интернете, никакой регистрации: вы открываете
её в обычном браузере, но доступна она только с этой машины. Ничего наружу не
отправляется.

Прогресс (какие уроки пройдены, как решены задания) хранится тут же, рядом с
платформой.

---

## 1. Что нужно поставить — одна программа

**[Docker Desktop](https://www.docker.com/products/docker-desktop/)** — скачать
с официального сайта и установить как любую другую программу.

Больше ничего ставить не надо. Всё, что нужно платформе внутри, Docker скачает
сам при первом запуске.

После установки:

- **На Windows перезагрузите компьютер** — установщик об этом попросит, это
  обязательно.
- Откройте Docker Desktop и дождитесь, пока внизу окна появится надпись
  **Engine running**. Дальше Docker можно не открывать никогда: наши команды
  запустят его сами, если он выключен.

На первый запуск нужен интернет — Docker будет скачивать составные части.
Потом интернет не нужен.

---

## 2. Запустить

### Windows

Откройте папку проекта, зайдите в `scripts` → `stack` и **дважды кликните по
файлу `start.bat`**.

Всё. Откроется чёрное окно, в нём по шагам будет написано, что происходит.

### macOS и Linux

Здесь нужна программа «Терминал» (на Mac она уже стоит: Программы →
Утилиты → Терминал).

1. Откройте Терминал.
2. Наберите `cd ` (три символа: c, d, пробел) — **и перетащите мышкой папку
   проекта прямо в окно Терминала**. Он сам подставит путь. Нажмите Enter.
3. Скопируйте туда эту команду и нажмите Enter:

   ```bash
   ./scripts/stack/start.sh
   ```

### Что вы увидите

```
  [1/5] Проверяю Docker
  [2/5] Проверяю настройки (файл .env)
  [3/5] Собираю и запускаю платформу
  [4/5] Жду, пока платформа будет готова
  [5/5] Готово
```

- **Самый первый запуск идёт несколько минут** — платформа собирается с нуля.
  Пробегающий технический текст читать не нужно, он для разработчиков.
- Дальше запуск занимает меньше минуты.
- В конце появится адрес:

  ```
      Открой в браузере:  http://localhost:3000
  ```

**Скопируйте этот адрес в браузер.** Браузер не открывается сам специально:
адрес печатается только тогда, когда платформа действительно готова отвечать,
а не «вот-вот будет готова».

Окно с командой после этого можно закрыть — платформа продолжит работать.

## 3. Обновили проект — пересоберите

Если вам прислали новую версию (или вы забрали её из репозитория), запускайте
не обычный запуск, а **пересборку**. Она сложит платформу заново, с нуля, и
гарантированно подхватит все изменения.

| Windows | macOS / Linux |
|---|---|
| двойной клик по `scripts\stack\rebuild.bat` | `./scripts/stack/rebuild.sh` |

Идёт столько же, сколько самый первый запуск, и требует интернета.
**Ваш прогресс при этом сохраняется** — пересобираются только программы, а не
данные.

> Почему нельзя просто запустить как обычно: Docker старается не делать
> лишнюю работу и переиспользует части, собранные в прошлый раз. Обычно он
> прав, но иногда оставляет что-то старое, и получается новая версия, которая
> ведёт себя как прежняя. Пересборка это исключает.

---

## 4. Остановить

| Windows | macOS / Linux |
|---|---|
| двойной клик по `scripts\stack\down.bat` | `./scripts/stack/down.sh` |

**Прогресс сохраняется.** Следующий запуск поднимет платформу ровно с тем же
содержимым. Просто закрыть окно браузера тоже можно — платформа останется
работать в фоне и не мешает.

## 5. Если что-то пошло не так

Команда не зависает молча: она либо доводит запуск до конца, либо пишет, что
именно сломалось и что с этим делать. Технический текст она печатает первым, а
понятное объяснение — **в самом низу**. Читайте снизу вверх.

| Написано | Что делать |
|---|---|
| `Docker не установлен` | поставить [Docker Desktop](https://www.docker.com/products/docker-desktop/) и перезагрузить компьютер |
| `Docker Desktop не поднялся за 180 сек` | открыть Docker Desktop и прочитать, что он просит (обычно — обновиться или перезагрузиться) |
| `нужный порт уже занят другой программой` | какая-то программа заняла адрес, нужный платформе — см. «Поменять адрес» ниже |
| `Docker не смог скачать нужные образы из интернета` | проверить интернет; если вы за корпоративным прокси или VPN — настроить его в Docker Desktop → Settings → Resources → Proxies |
| В браузере «Связи с ядром нет» | запустить команду запуска ещё раз: она дождётся и объяснит причину, если что-то действительно сломано |
| Изменения из новой версии не появились | сделать пересборку (раздел 3) |
| Окно мелькнуло и закрылось | вы кликнули по файлу `.ps1` — кликать надо по `.bat` |

Если в таблице нет вашего случая — **[docs/run.md](docs/run.md)** разбирает всё
то же самое подробно.

### Поменять адрес

Платформа по умолчанию живёт на `http://localhost:3000`. Если этот адрес занят
другой программой, откройте в папке проекта файл `.env` (он появится после
первого запуска) любым текстовым редактором и поменяйте число в строке:

```
FRONTEND_PORT=3000
```

например, на `3100`. Сохраните и запустите заново — адрес в конце будет уже
новый.

## 6. Где лежит прогресс и как его не потерять

Всё, что вы прошли, лежит в хранилище Docker под именем `trellis_pgdata`. Его
не трогают ни остановка, ни пересборка, ни перезагрузка компьютера.

Удалить его можно только одной специальной командой, и она обязательно
переспросит — придётся набрать слово `УДАЛИТЬ` целиком:

```bash
./scripts/stack/down.sh --with-data          # macOS / Linux
.\scripts\stack\down.ps1 -WithData           # Windows, из PowerShell
```

Восстановить данные после этого будет неоткуда, поэтому **сначала выгрузите
прогресс из самой платформы** — в интерфейсе есть экспорт, он сохраняет файл,
который потом можно загрузить обратно.

## 7. Для разработчиков

Node.js пользователю не нужен, но если он у вас есть, те же три команды
доступны короче и одинаково на всех системах:

```bash
npm start                 # запустить
npm run stack:rebuild     # пересобрать с нуля
npm run stack:down        # остановить
```
