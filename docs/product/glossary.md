# Glossary

- **Ядро (движок)** — специальность-агностичная платформа: прогресс, квизы, импорт/экспорт, Docker-оркестрация. Не содержит знаний о конкретном курсе.
- **Контент-пакет (курс)** — строго валидируемая структура данных (JSON/YAML): метаданные, модули → уроки, контент/квизы. Данные, а не код.
- **Модуль / урок** — единицы структуры курса; урок содержит текстовый контент и/или квиз.
- **Квиз** — вопрос, варианты ответа, единственно верный вариант, текст объяснения для каждого неверного варианта.
- **Песочница практики** — изолированный ресурс для практических заданий, который курс объявляет в своей конфигурации (для MVP — отдельная схема/роль в Postgres). Проектируется как интерфейс с несколькими возможными реализациями.
- **Прогресс** — состояние прохождения курса пользователем; сущность, развязанная с форматом определения курса.
- **Файл экспорта** — переносимый файл состояния прогресса с меткой времени последнего сохранения.
