# Практика: книги по году издания

`WHERE` отбирает строки, но ничего не говорит о том, в каком порядке они
придут: Postgres возвращает их в том порядке, в каком ему удобно. Когда
порядок важен, его задают явно — `ORDER BY`:

```sql
select title from books order by title;
```

По умолчанию сортировка идёт по возрастанию (`asc`), убывание задаётся
словом `desc`.

В этом задании порядок строк — часть ответа: движок сравнивает
последовательность строк, а не просто их набор. Тот же запрос без
`ORDER BY` зачтён не будет.
