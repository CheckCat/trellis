# Практика: retry с экспоненциальным backoff и дедлайном

Пишем правильный retry — с классификацией ошибок, экспоненциальной
задержкой, полным jitter-ом от внедрённой случайности и общим
дедлайном. Одна из самых частых задач live-coding, и почти все
забывают одну из четырёх составляющих.

## Модель

Функция-операция моделируется списком исходов по попыткам; время и
случайность — внедрённые.

```ts
type Attempt = "ok" | "transient" | "permanent";
// transient — сетевой сбой/503: повторяемо; permanent — 4xx/бизнес-отказ.

type Plan = {
  attempts: Attempt[];   // исход каждой попытки по порядку;
                         // если попыток больше, чем элементов, — последний повторяется
  baseMs: number;        // базовая задержка
  maxRetries: number;    // максимум ПОВТОРОВ (не считая первой попытки)
  deadlineMs: number;    // общий дедлайн от старта
  randoms: number[];     // значения «случайности» 0..1 для jitter, по одному на повтор
};
```

Правила:

- Попытка выполняется мгновенно (модельно) в момент `now` (старт — 0).
- `ok` — успех, конец. `permanent` — не повторяется: провал сразу.
- `transient` — если остались повторы и дедлайн позволяет, спланируй
  повтор с полным jitter-ом: `delay = floor(random × baseMs ×
  2^(номер_повтора − 1))`, где `random` — очередное значение из
  `randoms` (первый повтор — `randoms[0]`), номер_повтора — 1 для
  первого повтора. Новый `now = now + delay`.
- **Дедлайн**: если `now + delay > deadlineMs` — повтор не делается,
  провал по дедлайну. Проверка — до ожидания (не ждём, если не
  успеем).
- Исчерпаны повторы (`maxRetries`) — провал.

## Задание

Экспортируй функцию `runRetry(plan)`:

```ts
type RetryResult = {
  outcome: "ok" | "permanent" | "exhausted" | "deadline";
  attemptsMade: number;    // сколько попыток реально выполнено
  timeline: number[];      // моменты начала каждой попытки (первая — 0)
  totalMs: number;         // момент завершения (успеха или отказа) = момент последней попытки
};

export function runRetry(plan: Plan): RetryResult;
```

## Пример

```json
{
  "attempts": ["transient", "transient", "ok"],
  "baseMs": 100,
  "maxRetries": 3,
  "deadlineMs": 10000,
  "randoms": [0.5, 1.0]
}
```

Повтор 1: delay = floor(0.5 × 100 × 1) = 50 → попытка в 50.
Повтор 2: delay = floor(1.0 × 100 × 2) = 200 → попытка в 250.
Результат: `{outcome: "ok", attemptsMade: 3, timeline: [0, 50, 250],
totalMs: 250}`.

## Ловушки, которые проверяют случаи

- `permanent` со второй попытки — провал немедленно, оставшиеся
  повторы не тратятся.
- Дедлайн проверяется с учётом задержки: если запланированный повтор
  вылезает за дедлайн — исход `deadline`, попытка не выполняется, в
  `timeline` её нет.
- `maxRetries: 0` — одна попытка и всё.
- Jitter с `random = 0` — нулевая задержка, попытка в тот же момент.
- Показатель степени растёт по повторам: 1×, 2×, 4×.
