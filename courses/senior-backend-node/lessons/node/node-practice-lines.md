# Практика: строки и пакеты из потока чанков

Оператор загружает реестр — текстовый файл, по записи на строку.
Сервис читает тело запроса потоком: куски приходят произвольной длины,
и граница куска проходит где угодно — посреди строки. Задача, которую
решает любой парсер строк из потока: собрать целые строки, ни одной не
потеряв и ни одной не разорвав, и отдать их дальше пачками — например,
чтобы писать в базу по 100 записей за раз.

Это упрощённая модель того, что делает `readline` поверх потока, и то,
что просят написать на live-coding как проверку понимания потоков без
самих потоков: вход — массив кусков, выход — результат.

## Задание

Экспортируй функцию `batchLines(chunks, batchSize)`:

- `chunks` — массив строк, куски входа в порядке поступления. Считай,
  что это уже декодированный текст (о UTF-8 позаботился
  `setEncoding`).
- `batchSize` — максимальный размер пачки, целое число не меньше 1.

Функция возвращает массив пачек; каждая пачка — массив строк в порядке
их появления во входе. Правила:

- Строки разделяются `\n`. Перевод строки `\r\n` считается одним
  разделителем: `\r` в конец строки не попадает.
- Строка может начинаться в одном куске и заканчиваться в другом, в том
  числе через несколько пустых кусков.
- Пустые строки (два разделителя подряд) — тоже строки, они входят в
  результат как `""`.
- Если после последнего разделителя остался непустой хвост без `\n` —
  это последняя строка, её нужно включить. Если хвост пустой (вход
  закончился ровно на `\n`) — лишней пустой строки быть не должно.
- Пачки заполняются по порядку: все, кроме последней, ровно
  `batchSize` строк; последняя — остаток. Если строк нет вовсе —
  результат `[]`.

Заготовка:

```ts
export function batchLines(chunks: string[], batchSize: number): string[][] {
  // ...
}
```

## Примеры

```
batchLines(["a\nb\nc\n"], 2)          → [["a", "b"], ["c"]]
batchLines(["a\nb", "c\nd"], 10)       → [["a", "bc", "d"]]
batchLines(["x\r", "\ny"], 1)          → [["x"], ["y"]]
batchLines(["", "\n", ""], 3)          → [[""]]
batchLines([], 3)                      → []
```

Второй пример — суть задания: `"b"` из первого куска и `"c"` из
второго — одна строка `"bc"`.

## Подсказка без решения

Держи «хвост» — незавершённую строку между кусками. Каждый новый кусок
приклеивай к хвосту, разбирай всё до последнего разделителя, а то,
что после него, — новый хвост. В конце входа хвост, если он не пустой,
— последняя строка.
