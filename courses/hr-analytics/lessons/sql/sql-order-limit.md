# ORDER BY и LIMIT

Кого наняли последним? Кто дольше всех в компании? Такие вопросы — не про «какие строки взять», а про их порядок. В прошлом уроке мы отбирали строки; порядок же до сих пор был произвольным — база возвращала строки как ей удобно. Управляет порядком **ORDER BY**:

```sql
select name from departments order by name
```

| name |
|---|
| HR |
| Администрация |
| ИТ |
| Маркетинг |
| … |

Кстати, заметьте: `HR` встал раньше «Администрации» — при сортировке текста латиница идёт перед кириллицей. Это не ошибка, просто порядок символов.

## По убыванию и по нескольким столбцам

По умолчанию сортировка идёт по возрастанию (можно выписать явно: `asc`); по убыванию — `desc`:

```sql
select position, opened_on from vacancies order by opened_on desc
```

Первой строкой придёт самая свежая вакансия. Сортировать можно и по нескольким столбцам через запятую: `order by department_id, hire_date desc` — сначала строки группируются по отделу, а внутри одного отдела идут от самых новых сотрудников к давним. Второй столбец работает судьёй при равенстве первого.

## LIMIT: только первые N строк

**LIMIT** обрезает результат до указанного числа строк:

```sql
select position, opened_on from vacancies order by opened_on desc limit 3
```

| position | opened_on |
|---|---|
| кладовщик | 2025-12-15 |
| оператор линии | 2025-12-01 |
| менеджер по продажам | 2025-11-10 |

Вместе `order by` + `limit` — это «топ-N», один из самых ходовых приёмов аналитика: три последние вакансии, пять самых больших окладов, десять новичков.

## Осторожно: ничьи

`limit` без `order by` почти всегда ошибка: он отрежет первые попавшиеся строки в том самом непредсказуемом порядке. Но есть ловушка потоньше: сортировка по столбцу, где значения повторяются. Если на границе топа стоят три вакансии, открытые в один день, база выберет из них произвольно — сегодня одну, завтра другую. Когда однозначность важна, добавьте второй столбец-судью, у которого повторов нет: `order by opened_on desc, id`.

И последнее: `limit` — про *показ*, а не про смысл. «10 последних нанятых» — это `limit 10`; а вот «сотрудники, нанятые в 2025-м» — это условие `where`, сколько бы их ни оказалось. Не подменяйте условие обрезкой.

В задании ниже соберите топ-N сами — и помните, что порядок строк здесь часть правильного ответа.
