# SELECT: выбираем столбцы

Как попросить у базы список отделов? Пишем первый запрос — с команды **SELECT** начинается почти всё, что вы будете делать в SQL:

```sql
select name from departments
```

Читается ровно как просьба: «выбери столбец `name` из таблицы `departments`». База вернёт 8 строк — например, таких (про порядок строк поговорим ниже):

| name |
|---|
| Продажи |
| Маркетинг |
| Производство |
| Склад и логистика |
| ИТ |
| Финансы |
| HR |
| Администрация |

Два слова о форме. Регистр не важен: `SELECT`, `select`, `Select` — одно и то же (в уроках мы пишем строчными, в книгах чаще встретите заглавные). Названия таблиц и столбцов пишутся как в схеме. Запрос можно разбивать на несколько строк — базе всё равно, а читать легче.

## Несколько столбцов и все сразу

Столбцы перечисляются через запятую — и вернутся ровно в том порядке, в каком вы их назвали:

```sql
select name, id from departments
```

А звёздочка означает «все столбцы таблицы»:

```sql
select * from employees
```

`select *` удобен, чтобы быстро взглянуть на незнакомую таблицу. Но в отчётах перечисляйте столбцы явно: «все» — это и дата рождения, и пол, которые в отчёте о найме никому не нужны и которые вы, возможно, не вправе показывать.

## Псевдонимы и арифметика

Столбцу результата можно дать своё имя через `as` — это называется псевдоним. Имя пишите латиницей без пробелов. А ещё прямо в списке столбцов можно считать:

```sql
select full_name, fte, fte * 40 as hours_week from employees
```

Здесь третий столбец не существует в таблице — он вычислен: ставка, умноженная на 40-часовую неделю. Фрагмент результата:

| full_name | fte | hours_week |
|---|---|---|
| Лебедева Юлия Борисовна | 1.00 | 40.00 |
| Мартынов Никита Алексеевич | 0.50 | 20.00 |

Работают `+`, `-`, `*`, `/` и скобки — как в Excel, только формула применяется сразу к каждой строке таблицы.

## Что важно знать о результате

- **Порядок строк не обещан.** Пока вы не попросили сортировку явно (этому посвящён урок про ORDER BY), база возвращает строки в произвольном порядке. Сегодня один, завтра другой — и это нормально.
- **Платформа показывает первые 200 строк.** В `employees` 185 строк — такой результат вы увидите целиком; результат длиннее будет показан усечённым, но проверка задания при этом сравнивает результат полностью.
- Запрос ничего не меняет в базе: SELECT только читает. Экспериментируйте свободно.

Пока мы забираем столбцы у *всех* строк таблицы. Выбирать не всех, а, скажем, только работающих сотрудников — это условие WHERE, и им займёмся в следующем уроке.
