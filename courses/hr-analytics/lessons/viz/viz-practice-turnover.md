# Практика: дашборд текучести

Собираем первый настоящий дашборд — тот самый «один экран» про уходящих людей. Работа целиком в DataLens; платформа проверит результат по числам, которые вы снимете с готового экрана.

## Данные

Три файла из каталога данных курса (он лежит там, куда распакована платформа):

- `courses/hr-analytics/data/terminations.csv` — увольнения: дата, основание;
- `courses/hr-analytics/data/employees.csv` — сотрудники: здесь связь с отделом;
- `courses/hr-analytics/data/departments.csv` — названия отделов.

В увольнениях отдела нет — есть `сотрудник_id`. Свяжите таблицы в датасете: увольнение → сотрудник (по `сотрудник_id` и `id`), сотрудник → отдел (по `отдел_id` и `id`). DataLens умеет соединять таблицы одного подключения прямо в датасете — ищите добавление второй таблицы и настройку связи. Проверьте типы: обе даты должны распознаться датами (формат дд.мм.гггг, разделитель `;`).

## Что собрать

1. **Индикатор** — число увольнений за 2025 год, слева сверху.
2. **Столбчатый чарт** — увольнения 2025 года по отделам, отсортированные по убыванию.
3. **Линейный чарт** — увольнения по месяцам 2025 года.
4. **Селектор года** — чтобы директор мог переключиться на 2024-й и 2023-й; проверьте, что он действует на все три чарта. Для селектора пригодится вычисляемое поле «год увольнения» из даты.

Заголовки — выводами, не «График 1». Прогоните экран взглядом директора: главное число видно за три секунды?

## Что сдать

Снимите с готового дашборда три значения и впишите их в поля ниже. Отвечайте ровно тем, что показывает дашборд: числа — целыми, название отдела — как в данных.
