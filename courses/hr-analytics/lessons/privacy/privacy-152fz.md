# 152-ФЗ простыми словами

Почему табличку из кейса нельзя было отправлять — «по ощущениям» понятно. Но аналитику нужны не ощущения, а правило, на которое можно сослаться в споре с коллегой или руководителем. Правило есть: федеральный закон **152-ФЗ** «О персональных данных». Разберём его базовые положения — без юридических тонкостей, ровно в объёме, который нужен для работы с отчётами.

## Что такое персональные данные

**Персональные данные** — любая информация, относящаяся к определённому или определяемому человеку. Ключевое слово — «определяемому»: данные персональные не только когда рядом написана фамилия, но и когда до человека можно дотянуться по совокупности признаков. ФИО, дата рождения, телефон, паспорт — очевидные примеры. Но и оклад — персональные данные, как только он связан с человеком: строка «Попова Ольга Михайловна, отдел продаж, 84 000 ₽» из данных «Ромашки» — про конкретную Попову. А вот «средний оклад по компании — 83 967 ₽» — уже нет: из этого числа не определить ни одного человека. Разница между этими двумя строками — главный практический навык модуля.

## Оператор и основания обработки

Компания, которая собирает и использует данные сотрудников, по закону называется оператором персональных данных и отвечает за всё, что с этими данными происходит. Обрабатывать их просто «потому что удобно» нельзя — закон требует основания. Для HR основное основание — трудовые отношения: работодатель обязан вести кадровый учёт, платить зарплату, отчитываться перед государством, и для этого ему законно нужны данные работника. Заметьте границу: основание покрывает то, что нужно для трудовых отношений, — а не любое использование любых данных о сотруднике, которое пришло в голову.

## Минимизация

Закон требует обрабатывать ровно столько данных, сколько нужно цели, — этот принцип называют минимизацией. Для расчёта текучести по отделам нужны отдел, дата приёма и дата увольнения — и не нужны ФИО, даты рождения и оклады. Привычка «выгружу все столбцы, вдруг пригодится» — прямое нарушение принципа: каждый лишний столбец в файле — лишний риск, который вы создали без причины. Правило для каждого отчёта: перечислите цель, а потом вычеркните все поля, без которых цель достижима.

## Передача третьим лицам

Передавать персональные данные кому-то вне компании можно только когда на это есть законное основание — например, обязанность отчитаться перед налоговой или согласие самого человека. «Знакомая попросила для бенчмарка» основанием не является: сотрудники давали данные работодателю для трудовых отношений, а не для чужих исследований. Именно поэтому ответ в кейсе — «нет», и никакое «никому не покажу» этого не меняет: нарушение происходит в момент передачи, а не в момент огласки.

Держите в голове простую рамку: чьи данные — того и защита; у компании — обязанности оператора; у каждого использования — цель и основание; данных — минимум под цель. В следующем уроке — как готовить отчёты, в которых людей определить нельзя, и почему «убрать колонку ФИО» для этого недостаточно.
