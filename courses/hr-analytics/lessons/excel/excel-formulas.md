# Формулы для счёта: СЧЁТЕСЛИМН, СУММЕСЛИМН, работа с датами

«Сколько человек у нас работает прямо сейчас?» — вопрос на одну формулу, если данные лежат плоской таблицей. Весь расчёт метрик в Excel держится на двух функциях-сёстрах: одна считает строки по условиям, другая — суммирует.

## СЧЁТЕСЛИМН: посчитать строки по условиям

`=СЧЁТЕСЛИМН(диапазон1; условие1; диапазон2; условие2; …)` — сколько строк удовлетворяет **всем** условиям сразу.

Пример на `courses/hr-analytics/data/terminations.csv` (пути файлов — от каталога, куда распакована платформа). Сколько увольнений пришлось на 2025 год? Даты увольнения — в столбце C:

```
=СЧЁТЕСЛИМН(C:C; ">="&ДАТА(2025;1;1); C:C; "<="&ДАТА(2025;12;31))
```

Результат — 23. Разберём приём с датами: условие-сравнение склеивается из знака в кавычках и функции ДАТА через `&`. Можно написать и `">=01.01.2025"`, но ДАТА(год; месяц; день) надёжнее — она не зависит от того, в каком формате ваша система понимает даты.

## Пустые и непустые ячейки

Два специальных условия: `"="` — ячейка пуста, `"<>"` — ячейка непуста. В `vacancies.csv` пустой столбец «закрыта» означает, что вакансия ещё открыта:

```
=СЧЁТЕСЛИМН(E:E; "<>")   → 51 закрытая вакансия
=СЧЁТЕСЛИМН(E:E; "=")    → 4 ещё открыты
```

Тот же приём — ключ к вопросу из начала урока: в `employees.csv` пустая «дата увольнения» означает, что человек работает.

## СУММЕСЛИМН: просуммировать по условиям

`=СУММЕСЛИМН(что_суммируем; диапазон1; условие1; …)` — первым аргументом идёт столбец, который складываем, дальше — те же пары «диапазон; условие».

Пример: суммарная ставка работающих в Администрации (в `employees.csv` отдел_id Администрации — 8, ставка — столбец I, дата увольнения — H):

```
=СУММЕСЛИМН(I:I; E:E; 8; H:H; "=")   → 4,5
```

Людей в Администрации при этом шестеро: трое работают на полставки, у них в столбце «ставка» стоит 0,5. Отсюда важное предупреждение: дробные числа в файлах курса записаны **с запятой** («0,5»). Если после открытия файла такие значения прижаты к левому краю ячейки — Excel прочитал их как текст, и СУММЕСЛИМН молча посчитает их за ноль. Так бывает, когда файл открыт не в русской настройке разделителей; проверьте столбец глазами до того, как верить сумме.

## Разность дат — это дни

Дата в Excel — число, поэтому даты можно вычитать: `=E2-D2` для вакансии даст срок от открытия до закрытия в днях, «дата увольнения» минус «дата приёма» — стаж в днях. Для среднего по условиям есть третья сестра — СРЗНАЧЕСЛИМН, устроенная как СУММЕСЛИМН.

Ещё две мелочи, без которых формулы не протягиваются: знак `$` в ссылке (`$A$2:$B$9`) закрепляет диапазон, чтобы он не съезжал при копировании формулы вниз; а протягивать формулу на весь столбец удобнее двойным щелчком по правому нижнему углу ячейки.

## В LibreOffice и Google Sheets — то же самое

Логика и аргументы совпадают один в один, отличаются только имена функций (даю один раз, дальше пользуйтесь таблицей):

| Русский Excel | LibreOffice / Google Sheets |
|---|---|
| СЧЁТЕСЛИМН | COUNTIFS |
| СУММЕСЛИМН | SUMIFS |
| СРЗНАЧЕСЛИМН | AVERAGEIFS |
| СРЗНАЧ | AVERAGE |
| ДАТА | DATE |
| ГОД | YEAR |
| СЖПРОБЕЛЫ | TRIM |
