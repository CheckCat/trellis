# Сводные таблицы: текучесть по отделам за минуту

«Сколько увольнений в каждом отделе?» Формулами это восемь СЧЁТЕСЛИМН — по одной на отдел. Захотел директор ещё и по годам — уже двадцать четыре. А следующий вопрос потребует переписать всё заново. Сводная таблица решает тот же класс задач перетаскиванием полей: разрез «что-нибудь × что-нибудь» собирается за минуту и пересобирается за секунды.

## Четыре области

Выделите плоскую таблицу, «Вставка» → «Сводная таблица» — справа появится макет с четырьмя областями:

- **Строки** — чем группируем вниз (отдел, источник, основание увольнения);
- **Столбцы** — чем группируем вбок (обычно период: год, месяц);
- **Значения** — что считаем в ячейках пересечения (количество строк, сумма, среднее);
- **Фильтры** — что ограничиваем, не показывая в таблице (например, только один год).

Сводная не трогает исходные данные — она строит расчёт поверх них, как отчёт из урока про плоские таблицы, только живой.

## Ловушка: сумма вместо количества

Перетащите в «Значения» числовое поле — Excel по умолчанию предложит «Сумма». Для поля «id» это даст сумму порядковых номеров: большое число, не значащее ничего. Когда нужен ответ «сколько строк» — щёлкните по полю в области значений → «Параметры поля значений» → «Количество». Проверять, **что** именно посчитано в ячейке, — первый рефлекс работы со сводными.

## Группировка дат

Перетащите «дату увольнения» в строки — получите по строке на каждую дату. Правый щелчок по любой из них → «Группировать» → выберите «Месяцы» и «Годы» — и даты сложатся в разрез по месяцам без единой формулы. Работает это только с настоящими датами: столбец, где половина значений — текст, группироваться откажется. Вот где окупается чистка.

## Пример: увольнения по отделам

Соберём разрез по `courses/hr-analytics/data/terminations.csv` (путь — от каталога, куда распакована платформа). Честное предупреждение: отдела в этом файле **нет** — там только «сотрудник_id». Нужен промежуточный шаг из прошлого урока, причём двойной: первым ВПР подтяните к увольнению «отдел_id» из `employees.csv` (по сотрудник_id), вторым — название отдела из `departments.csv`. Только после этого стройте сводную: отдел — в строки, «id» — в значения количеством.

За все три года верх таблицы выглядит так: Продажи — 19, Производство — 19, Склад и логистика — 14, всего по компании — 65. Теперь добавьте «дату увольнения» в фильтры (или годы группировкой в столбцы) — и это уже разрез за любой период по вашему выбору. Что получилось за 2025-й — узнаете сами: этому посвящена практика в конце модуля.

Заголовок урока не преувеличивает: когда данные плоские и чистые, путь от вопроса директора до готового разреза — действительно минута. Всё время аналитика уходит не на сводную, а на подготовку данных к ней — поэтому уроки шли именно в таком порядке.
