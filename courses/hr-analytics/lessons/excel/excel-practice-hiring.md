# Практика: свод по найму «Ромашки»

Директор спрашивает: «Как у нас в этом году с наймом?» Ответ — три числа, и все три считаются по двум файлам (пути — от каталога, куда распакована платформа):

- `courses/hr-analytics/data/vacancies.csv` — вакансии: id; отдел; должность; открыта; закрыта (пустая = вакансия ещё открыта); нанят_id;
- `courses/hr-analytics/data/applications.csv` — отклики: id; вакансия_id; кандидат; источник; дата отклика; этап.

Инструменты — из уроков этого модуля, план такой.

**Закрытые вакансии.** Число вакансий, закрытых в 2025 году, — одна СЧЁТЕСЛИМН по столбцу «закрыта» с условиями-датами через `">="&ДАТА(…)`.

**Срок закрытия.** Это тот самый time-to-fill из модуля 1. Разность дат в Excel — уже число дней, поэтому добавьте в `vacancies.csv` вспомогательный столбец «закрыта минус открыта», а среднее только по закрытым в 2025-м возьмите через СРЗНАЧЕСЛИМН с теми же условиями на дату закрытия.

**Отклики на закрытые вакансии.** В `applications.csv` даты закрытия нет — есть только «вакансия_id». Подтяните дату закрытия ВПР-ом из `vacancies.csv` (по вакансия_id, точное совпадение — ЛОЖЬ), а затем посчитайте СЧЁТЕСЛИМН по подтянутому столбцу. Обратите внимание: фильтровать нужно по дате **закрытия вакансии**, а не по дате отклика — отклики на вакансии 2025 года могли приходить и в 2024-м.

Впишите три числа в поля под уроком. Округление — как указано в подписи поля.
