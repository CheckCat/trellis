# ВПР и ИНДЕКС/ПОИСКПОЗ: соединяем таблицы

В `employees.csv` у сотрудника вместо отдела — число: отдел_id. Названия лежат в другом файле, `courses/hr-analytics/data/departments.csv` (путь — от каталога, куда распакована платформа). Как получить в списке сотрудников столбец с названием отдела, не вписывая его руками 185 раз?

Для этого есть ВПР — «вертикальный просмотр» (в англоязычных Excel, LibreOffice и Google Sheets она называется VLOOKUP):

```
=ВПР(что_ищем; где_ищем; номер_столбца; интервальный_просмотр)
```

Порядок действий. Скопируйте содержимое `departments.csv` на отдельный лист «справочник» (столбец A — id, столбец B — отдел). В файле сотрудников добавьте столбец:

```
=ВПР(E2; справочник!$A:$B; 2; ЛОЖЬ)
```

Формула берёт значение E2 (отдел_id, у первого сотрудника это 1), ищет его в **первом** столбце диапазона `A:B` и возвращает значение из столбца номер 2 той же строки — «Продажи». Знаки `$` закрепляют диапазон, чтобы при протягивании формулы вниз он не съехал.

## Четвёртый аргумент: всегда ЛОЖЬ

ЛОЖЬ означает «точное совпадение»: нашлось ровно такое значение — вернуть результат, не нашлось — сказать об этом. Если аргумент пропустить или поставить ИСТИНА, включается **интервальный просмотр**: ВПР предполагает, что справочник отсортирован по возрастанию, и ищет «последнее значение, не превышающее искомое». На несортированных данных это возвращает значения из чужих строк — **без всякой ошибки**, просто тихо неверно. Таблица выглядит заполненной, числа в ней — ложь. Поэтому правило простое: четвёртый аргумент — ЛОЖЬ, всегда, не раздумывая.

## #Н/Д — это не поломка

Если точного совпадения нет, ВПР возвращает `#Н/Д` — «нет данных». Это информация, а не ошибка формулы: либо в ключе опечатка (помните пробелы из урока про чистку?), либо такого значения в справочнике действительно нет. Например, в `vacancies.csv` у ещё открытых вакансий пуст столбец «нанят_id» — ВПР по нему честно вернёт `#Н/Д`, и это правильный ответ: нанятого пока нет. Формула `=ЕСЛИОШИБКА(ВПР(…); "")` покажет вместо `#Н/Д` пустоту — но применяйте её только тогда, когда понимаете, откуда `#Н/Д` берётся: вместе с «законными» пропусками она скроет и опечатки в ключах.

## Ограничение ВПР и запасной инструмент

ВПР ищет только в первом столбце диапазона и возвращает значения из столбцов **правее** него. Задача «по названию отдела найти его id», когда id стоит левее названия, ВПР не решается. Выход — пара ИНДЕКС/ПОИСКПОЗ (INDEX/MATCH):

```
=ИНДЕКС(справочник!$A:$A; ПОИСКПОЗ("Финансы"; справочник!$B:$B; 0))
```

ПОИСКПОЗ находит номер строки со значением «Финансы» в столбце поиска, ИНДЕКС возвращает значение этой строки из любого нужного столбца — хоть левее, хоть правее. Ноль третьим аргументом ПОИСКПОЗ — то же «точное совпадение», что ЛОЖЬ у ВПР. Для повседневного «подтянуть название по id» хватает ВПР; ИНДЕКС/ПОИСКПОЗ держите на случай, когда столбец поиска стоит не первым.
